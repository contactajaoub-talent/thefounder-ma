# thefounder.ma

Programme opérationnel de 90 jours pour entrepreneurs et dirigeants.

## Stack

- React 18 + Vite
- Salesforce Web-to-Lead
- Calendly inline embed
- Deployed on Vercel

## Setup

```bash
npm install
npm run dev
```

## Deploy

Push to `main` branch → Vercel auto-deploys.

## Configuration

- **Salesforce OID**: Already set in `src/App.jsx`
- **Google Analytics**: Uncomment and add your GA4 ID in `index.html`
- **Meta Pixel**: Uncomment and add your Pixel ID in `index.html`
