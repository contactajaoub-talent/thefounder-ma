## Méthode et limites

Vérification du texte des publications / résumés éditeurs et du rapport Capgemini, plutôt que de reprendre seulement les extraits promotionnels. Le libellé « realized/expected » de la figure 16 est plus prudent que la page promotionnelle ; il a priorité dans le site.

Les sources sont liées dans chaque indicateur, avec année et contexte. Le format décimal français est conservé. Les liens externes s’ouvrent dans un nouvel onglet avec `noopener noreferrer`. La disponibilité d’un lien peut évoluer ; vérifier de nouveau juste avant publication.
